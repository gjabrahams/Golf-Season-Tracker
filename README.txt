Golf Season Tracker - Admin + View Only

ADMIN
1. Open index.html.
2. Add scores, Betterball results, players, courses and opposition.
3. Your editable data remains stored locally in your browser.
4. Use Export Backup regularly.

SHARE WITH FRIENDS (VIEW ONLY)
1. In the Admin website click Create Read-Only Viewer.
2. This downloads Golf_Season_Viewer.html containing the latest results.
3. Save/replace that file in your OneDrive folder.
4. Share it with friends as view-only.
5. Friends can view dashboards, Betterball results and 3-player comparisons, but there are no editing controls.

UPDATING THE SHARED COPY
After entering new results, click Create Read-Only Viewer again and replace the old viewer file in OneDrive.

A sample Golf_Season_Viewer.html is included in this package.


CSV EXPORT / IMPORT
- Admin now has Export CSV and Import CSV.
- The CSV stores both individual MATCH records and BETTERBALL records.
- RecordType identifies each row.
- Import CSV replaces the current match and betterball result data with the imported CSV content.
- Player, Course and Opposition master lists are automatically expanded from imported records.
- Use Export Backup (JSON) for a full backup including master lists; CSV is ideal for editing results in Excel.


SEASON FILTERS
- Dashboard can show All Seasons or one selected season.
- 3 Player Comparison can compare players within a selected season.
- Betterball results can be filtered by season.
- Viewer page includes the same season filters.

CSV IMPORT
- Import CSV is available in Admin.
- Import Mode: Replace replaces current match/Betterball data.
- Import Mode: Append adds imported rows to existing data.
- Season values in the CSV are preserved, allowing multi-season history.


CSV IMPORT
- Open Individual Matches.
- Choose Append CSV or Replace with CSV.
- Click Import CSV and select the file.
- Supports normal individual CSV files and Betterball CSV files.
- Imported Season values are kept and appear in the season filters.
- Two sample import templates are included in this ZIP.


V5 CHANGES
- Player names are filtered to players who have data in the selected season.
- Match History now has its Season and Player filters in the Match History heading.
- Betterball has a Season filter in the Betterball heading.
- 6 Player Comparison player selectors are now inside the table column headings.
- Comparison player choices are filtered by the selected comparison season.
- Read-only Viewer has the same filtering behaviour.
